# Supply Chain Analytics – SQL Project

## Project Overview
This project analyses supply chain data using PostgreSQL to understand sales performance, profitability, shipping operations, and delivery risk.

## Tools Used
- PostgreSQL
- SQL
- DBeaver

## Dataset
DataCo Supply Chain Dataset.

## Analysis Performed
1. Database Exploration
2. Dataset Exploration
3. Sales and Profit Analysis
4. Delivery Status Analysis
5. Shipping Mode Analysis
6. Late Delivery Risk Analysis
7. Category Performance Analysis
8. Market Performance Analysis
9. Regional Performance Analysis

## SQL Concepts Used
- SELECT, WHERE
- GROUP BY, ORDER BY
- Aggregate Functions: SUM, COUNT, AVG
- CASE WHEN
- DISTINCT
- ROUND
- Information Schema

## Project Files
- `Supply_Chain_Analysis.sql` – SQL queries used for the analysis.

## Project Objective
To explore supply chain data and identify insights related to sales, profitability, shipping methods, and delivery risk.
